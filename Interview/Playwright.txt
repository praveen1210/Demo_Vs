How do you design a scalable automation framework?

"When I design a scalable automation framework, I focus on modularity, reusability, maintainability, 
and ease of execution across different environments. I follow design patterns like the Page Object Model, 
separate test logic from page interactions and test data, and use configuration files so the same 
tests can run across multiple environments without code changes. I also integrate reporting, logging, 
CI/CD, and parallel execution to ensure the framework can grow with the application."
